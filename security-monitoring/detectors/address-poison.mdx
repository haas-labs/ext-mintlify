Detector monitor for transaction history poisoning with fake addresses

## Functionality

- Detector monitors transaction history for injection of fake transactions and events which resemble monitored address.

Poisoned address looks very similar in history because first and last 2-3 bytes are identical. 

Copy-pasting poison address from history can result in funds loss
- Mask for matching address to poisoning pattern. 
- How many historical transaction to check for poisoning
- How far into the past to keep transactions history (in milliseconds)

## Configuration

- **Past** (`past`, default: `2592000000`): How long to monitor history into the past
- **History** (`history`, default: `25`): How many past transactions to monitor
- **Patterns** (`patterns`, default: `['0xffff00000000000000000000000000000000ffff']`): Address match patterns
- **Severity** (`severity`, default: `0.5`): Severity See [common configuration](/common-configurations#severity).

<Note>
  Supported networks: ethereum, bsc.
</Note>
