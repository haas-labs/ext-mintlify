Detector monitors Blockchain for Block reorgs

## Functionality

- Protocol Layer reorg is when blockchain replaces blocks with another sub-chain. 

Previously observed block at re-org depth will not be part of blockchain
- How deep reorg to monitor for

## Configuration

- **Depth** (`depth`, default: `2`): Depth or reorg to detect
- **Severity** (`severity`, default: `-1`): Severity See [common configuration](/common-configurations#severity).

<Note>
  Supported networks: ethereum.
</Note>
