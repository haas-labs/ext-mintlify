---
title: "Advanced Monitoring"
description: "Define custom conditions on your smart contracts and get alerted the moment they are met."
---

Advanced Monitoring lets you go beyond built-in detectors and write your own rules. A trigger watches for a specific condition — a function call, a token transfer above a threshold, a blacklisted address — and fires an alert the instant it happens.

<Info>
  All triggers share a common set of parameters. See [Common Configurations](/common-configurations) for details on severity levels, cron schedules, and condition syntax.
</Info>

## Available triggers

<CardGroup cols={1}>
  <Card title="ERC-20 Transfer" icon="money-bill-transfer" href="/advanced-monitoring/triggers/erc20-transfer">
    Fires when a token transfer exceeds a configured amount. Filter by direction (from / to / any) and token contract.
  </Card>
  <Card title="Blacklisted Callers" icon="ban" href="/advanced-monitoring/triggers/blacklisted-callers">
    Fires when a transaction is initiated by an address on your blacklist. Useful for sanctions enforcement and post-exploit containment.
  </Card>
  <Card title="Function Call" icon="code" href="/advanced-monitoring/triggers/function-call">
    Fires whenever a specific contract function is executed. Optionally filter by transaction value.
  </Card>
</CardGroup>

## Common parameters

Every trigger shares these base fields:

| Parameter | Description |
|-----------|-------------|
| **Name** | Descriptive label shown in alerts |
| **Severity** | `Critical` · `High` · `Medium` · `Low` · `Info` · `Auto` |
| **Notification channels** | Where alerts are delivered — email, webhook, Slack, etc. |
