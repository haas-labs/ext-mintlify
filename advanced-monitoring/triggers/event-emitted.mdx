---
title: "Event Emitted"
description: >-
  This trigger alerts you whenever an event is emitted from your smart contract, giving you real-time visibility into what's happening.
---

**Detector Configuration**

<Steps>
  <Step title="Name">
    Enter a descriptive name for your trigger, for example: "Event Emitted".
  </Step>
  <Step title="Event">
    Execution of certain actions within the contract.
  </Step>
  <Step title="Include Transaction Value">
    Configure the transaction value filter:
    - *Operator*
    - *Transaction Value*
  </Step>
</Steps>
