---
title: "Trigger types"
description: "Advanced monitoring triggers let you define precise on-chain conditions — function calls, events, transfers, and parameters — that fire real-time alerts."
---

Triggers watch your smart contracts at the transaction level. Each trigger evaluates a specific condition — a token transfer amount, a function being called, an event being emitted — and fires an alert when that condition is met.
