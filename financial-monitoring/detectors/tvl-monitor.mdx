TVL Monitor tracks liquidity changes for ERC20 tokens & contracts by referencing your pre-configured thresholds. If the balance of a particular asset declined below a threshold, Extractor will notify your team.

## Functionality

- You can monitor two types of assets for TVL monitoring: ERC-20 tokens and Native coin of the network
- To define a ERC-20 token for monitoring you need to specify its address and threshold for Value Locked for that particular asset
- To include Native coin holdings for TVL monitoring you need to click on "Monitoring Native Token" checkbox and to provide a threshold as well.
- To define a threshold, specify the absolute value or the percentage with '%' sign
- No, in the current version, each threshold is set regarding particular asset (ERC-20 token of Native coin)
- No, you will be notified only about balances change of the assets you have specified for the monitoring.

## Configuration

- **Monitoring Tokens** (`tokens`, default: `None`): Monitoring Tokens
- **Native Token** (`native_token_status`, default: `True`): Monitoring Native Token
- **Native Token Threshold** (`native_token_threshold`, default: `1%`): Native Token Threshold, the value can be entered as absolute value or as percentage (with '%' sign)
- **Severity** (`severity`, default: `0.5`): Event Severity See [common configuration](/common-configurations#severity).

<Note>
  Supported networks: evm.
</Note>
