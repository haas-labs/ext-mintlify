---
title: "Setup Action"
description: "How to create and run Smart Contract Actions manually or automatically in response to triggers."
---

To activate Smart Contract Action you need to complete the following steps:

<Steps>
  <Step title="Create an action provider">
    [Create an action provider](/smart-contract-actions/action-providers/create-action-provider)
  </Step>
  <Step title="Open Actions page">
    ![Actions page](/assets/create_action_1.png)
  </Step>
  <Step title="Click Create Action">
    ![Create Action button](/assets/create_action_2.png)
  </Step>
  <Step title="Configure the action">
    * Enter action name.
    * Choose function you want to execute.
    * Choose Trigger/Detector you want to run action (optionally, can be run manually).
    * Enter gas (optionally).
    * Click on **Create Action** button.

    ![Action setup form](/assets/create_action_3.png)
  </Step>
  <Step title="Action created">
    ![Action created](/assets/create_action_4.png)
  </Step>
</Steps>

Contract Action will be called automatically in response to a trigger and in case you have enough funds on the Action Provider balance to cover the transaction gas fee. You can also run action manually if you need.

## Run Manually

<Steps>
  <Step title="Open the action menu">
    Click on the action menu and select **Run Manually**.

    ![Run Manually menu](/assets/run_action_1.png)
  </Step>
  <Step title="Configure the manual run">
    * Choose severity (optionally, info by default).
    * Enter alert message (optionally, detector/trigger message by default).
    * Enter gas (optionally, market values by default).
    * Click on **Run** button.

    ![Run action form](/assets/run_action_2.png)
  </Step>
</Steps>
