Clicking on any provider in the Action Providers list opens its detail page. This page shows the provider's current state and full activity history.

## Header

The header displays the provider's core information:

| Field | Description |
|---|---|
| **Name** | The label you assigned when creating the provider. |
| **Network** | The blockchain network this provider is registered on. |
| **Type** | `pk` (Default — private key provided or auto-generated by Extractor) or `HSM`. |
| **Address** | The wallet address. Use the **Copy** icon or click the external link to view it on a block explorer. |
| **Balance** | Current native token balance available for gas fees. |

The header also contains three action buttons:

| Button | Description |
|---|---|
| **Deposit** | Add native tokens to the provider's balance. |
| **Withdraw** | Send the remaining balance to an external wallet. |
| **Refresh** | Reload the balance from the chain. |

Clicking **···** (more options) reveals:
- **Edit Provider** — update the provider name, tags, or type.
- **Delete Provider** — permanently remove the provider.

<Warning>
  Deleting a provider does not automatically disconnect it from any contracts or remove configured actions. Make sure to update your contract permissions and action configurations before deleting.
</Warning>

## Transaction History tab

The **Transaction history** tab shows all transactions executed by this provider, including automated actions triggered by monitoring events and manual executions.

### Filters

| Filter | Description |
|---|---|
| **Severity** | Filter by alert severity: Any, Critical, High, Medium, Low, or Info. The count badge shows the number of transactions at each level. |
| **Date range** | Narrow results to a specific time window. |
| **UTC Timezone** | Toggle to display timestamps in UTC instead of local time. |

### Columns

| Column | Description |
|---|---|
| **Name** | The name of the smart contract action that was executed. |
| **Severity** | Severity level of the monitoring event that triggered the action. |
| **Tx Value** | Value transferred in the transaction (native token). |
| **Date and time** | Timestamp of the transaction. |
| **UID** | Unique identifier for the transaction record. |

## Connected Actions tab

The **Connected actions** tab lists all smart contract actions currently configured to use this provider.

### Columns

| Column | Description |
|---|---|
| **Name** | The name of the configured action. |
| **Last updated** | When the action configuration was last modified. |
| **Status** | Whether the action is active, paused, or errored. |
| **Gas price** | The gas price setting used for this action's transactions. |
| **Gas limit** | The maximum gas units allowed per transaction for this action. |

<Tip>
  If you see "You have no actions yet", go to [Set up a Smart Contract Action](/smart-contract-actions/setup-action) to create one and link it to this provider.
</Tip>
