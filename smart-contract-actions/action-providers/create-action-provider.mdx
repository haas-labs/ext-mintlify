---
title: "Create Action Provider"
description: "Step-by-step guide to creating an Action Provider in Hacken Extractor."
---

To create the Action Provider you need to accomplish the following steps:

<Steps>
  <Step title="Open Action Providers">
    Navigate to the Action Providers section in the app.

    ![Open Action Providers](/assets/create_provider_1.png)
  </Step>
  <Step title="Click on Add provider">
    ![Add provider](/assets/create_provider_2.png)
  </Step>
  <Step title="Configure and save">
    Choose the network, enter Provider name and click **Save**.

    ![Configure provider](/assets/create_provider_3.png)
  </Step>
  <Step title="Action Provider created">
    ![Action Provider created](/assets/create_provider_4.png)
  </Step>
</Steps>

As a next step, you should connect it to the contract and transfer funds to Provider's address.
