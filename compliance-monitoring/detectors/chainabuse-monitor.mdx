Detector monitors Chainabuse alerts

## Functionality

- Chainabuse categories list to filter (`PHISHING`,`OTHER_HACK`, ...). Use `!` prefix to exclude category.

If empty, all categories will be alerted

See Chainabuse documentation for supported categories
- Cron expression for interval to check. Reports are cached internally. 

Cron expression can be Quartz syntax, milliseconds value or seconds/minutes/hours/days expression (e.g. `5 hours`)

Example: `0 0 12 1/1 * ? *`

## Configuration

- **Category** (`category`, default: ``): Categories to filter
- **Cron** (`cron`, default: `1 day`): Check Interval See [common configuration](/common-configurations#cron).
- **Severity** (`severity`, default: `0.2`): Severity See [common configuration](/common-configurations#severity).

<Note>
  No specific network configuration required (Any network).
</Note>
