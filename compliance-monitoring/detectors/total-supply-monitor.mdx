The Total Supply Monitor is a daily monitoring tool designed to track the total supply of a token. It will send alerts if the total supply of the token exceeds the expected value. This monitor offers users insights into token distribution trends and ensuring compliance with time-based reporting needs, helping maintain consistency and transparency in token supply.

## Functionality

- The Expected value fields require whole token values, not raw units. This input is compared against the on-chain supply, normalized using the configured Decimals. Ensure the Decimals value is accurate, as incorrect settings will distort the calculated supply magnitude and prevent alerts.

## Configuration

- **Expected Total Supply** (`expected_total_supply`, default: `None`): Expected Total Supply
- **Expected Total Issued Tokens** (`expected_total_issued`, default: `None`): Expected Issued Tokens
- **Token decimals value** (`decimals`, default: `18`): Token decimals value
- **Severity** (`severity`, default: `-1`): Severity See [common configuration](/common-configurations#severity).

<Note>
  Supported networks: evm.
</Note>
