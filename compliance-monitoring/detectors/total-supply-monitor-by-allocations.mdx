The Total Supply Monitor by Allocations is a detector that monitors the total supply of a token by allocations. It checks the total supply of a token by comparing the expected total supply with the actual total supply.

## Functionality

- See configuration parameters below.

## Configuration

- **Token decimals value** (`decimals`, default: `18`): Token decimals value
- **Severity** (`severity`, default: `-1`): Severity See [common configuration](/common-configurations#severity).

<Note>
  Supported networks: evm.
</Note>
